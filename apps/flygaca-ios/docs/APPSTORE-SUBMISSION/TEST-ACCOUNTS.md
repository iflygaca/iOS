## Firebase Project Configuration

### Firestore Database Structure

All three apps read/write to the **same Firebase project** (`flygaca-app`). Cross-app progress sync works via:

1. **SwiftData local store** (per-app, persistent)
2. **Firestore cloud store** (optional, shared across apps)
3. **App Group** (`group.com.FlyGACA`, local, no internet needed)

### Firestore Rules (Read/Write Security)

**Production rules enforce:**

```firestore
match /databases/{database}/documents {
  // User progress collection
  match /users/{uid}/progress/{document=**} {
    allow read, write: if request.auth.uid == uid;
  }
  
  // Public regulations (read-only)
  match /regulations/{document=**} {
    allow read: if true;
    allow write: if false;
  }
}
```

**For App Review:**
- Test account has full read/write access to its own `/users/{uid}/` documents
- No write access to public regulations (immutable, GACA-sourced)
- No access to other users' data

### Firebase Authentication Configuration

**Enabled providers:**
- ✅ Email/Password
- ✅ Google OAuth (optional, not required for offline study)
- ✅ Apple Sign-In (optional, not used in current shipping version)

**App Check (Device Attestation):**
- ✅ Enabled for both iOS apps (`com.flygaca.elpt`, `com.flygaca.aip`)
- DeviceCheck tokens validated on Firestore access
- Fails gracefully: if Device Check unavailable → app continues in offline mode (no error to user)

## Troubleshooting During Review

### Issue: Sign In Fails ("Invalid Credentials")

**Solution:**
1. Verify password is current (check 1Password, refresh if >30 days old)
2. Try signing out + signing back in
3. Check internet connection (Device Check requires brief network call)
4. If error persists: Report to Support (appReview@flygaca.com with timestamp)

### Issue: "App Check Failed" or "Device Not Registered"

**Causes:**
- Device Check unavailable (rare on iOS 17+)
- Simulator used without proper Device Check emulation

**Solution:**
1. Use real iOS device if possible (iPhone 15 Pro, iPhone 14+)
2. Simulator fallback: Device Check tokens mocked (App Check succeeds with mock attestation)
3. App continues in offline mode (no study data is lost)

### Issue: Progress Not Syncing to Cloud

**Diagnose:**
1. Verify signed in: Settings → "Signed in as: appReview@flygaca.com"
2. Check sync status: "Last synced: [timestamp]"
3. Verify network: Settings → check WiFi is connected

**Solution:**
1. Toggle Airplane Mode off/on to force network check
2. Wait 2–3 seconds for auto-sync to trigger
3. Manual sync: Go to Settings → "Sync Now" button (if available)
4. If still failing: Check internet connection quality (poor WiFi can delay sync)

### Issue: Airplane Mode Test Doesn't Show "Offline" Badge

**Expected behavior:**
- Offline badge may not always be visible (implementation detail per screen)
- Quiz/flashcards/exam still work offline (that's the proof)
- Badge is visual confirmation, not required

**To verify offline mode:**
1. Enable Airplane Mode
2. Open FlyGACA app (already loaded)
3. Start quiz → questions load from bundled content (instant, no loading)
4. Answer questions → results calculated locally
5. Disable Airplane Mode → auto-sync triggers (no user prompt)

### Issue: Bilingual Test Shows Missing Strings

**Causes:**
- Arabic translation incomplete
- Font not loading (Cairo font unavailable)

**Solution:**
1. Check device language: Settings → General → Language (set to "English" or "العربية")
2. Force app language toggle: Settings in-app → Language toggle
3. Restart app
4. If strings still missing: Report specific screen/string in feedback to Support

## Account Reset & Monthly Maintenance

### Monthly Reset (1st of each month)

**Purpose:** Keep test account fresh for new submission cycles.

**Steps:**
1. **Clear app data:** Settings → "Clear Local Data" (in all 3 apps)
2. **Reset Firestore data:**
   - Firebase Console → Firestore → Collection `/users/{appReviewUID}/`
   - Delete all documents (clears quiz scores, flashcard progress, exams)
3. **Rotate password:** Generate new password, update in 1Password
4. **Verify:** Sign out, sign in with new password, confirm sync works

## Security & Privacy Notes

### Data Retention

Test account data is **retained indefinitely** for:
- Regression testing
- Support/troubleshooting
- Audit trails (Firebase audit logs)

**Reviewers' personal data:** None collected. App does not store or transmit reviewer identities, device IDs, or interaction logs. Only study progress (quiz scores, flashcard state, exam results) stored in Firestore under test account UID.

### Password Management

- Password **NOT** stored in this repository (encrypted in 1Password only)
- Password rotated monthly (1st of each month)
- Previous passwords never reused
- All password changes logged in 1Password audit trail

### Firestore Access

- Test account can only access its own `/users/{uid}/` data
- Cannot read/write other users' data
- Firestore rules enforce read/write permissions per UID
- All access logged in Firebase audit logs
